# Project Documentation Context (Non-Obvious Only)

- `src/main/resources/maven-wrapper/` contains the Maven Wrapper files that are *embedded in the fat JAR* and extracted at runtime by `MavenWrapperInstaller` — they are not for this project's own builds.
- `src/main/resources/META-INF/native-image/resource-config.json` is generated by picocli-codegen annotation processor for GraalVM native image support; edit with care.
- The `--debug` flag writes a log file AND a ZIP archive (`e2m_debug_<datetime>.zip`) created by `DebugArchiver` — these are two separate outputs.
- Servlet version in `.settings/org.eclipse.wst.common.project.facet.core.xml` maps to Java EE / Jakarta EE API coordinates via `JavaEEVersion.fromWebVersion()`. Servlet 2.x is treated as 3.0 (oldest supported).
- `chatlog/`, `*-plan.md` files in the root are development history/planning documents — not part of the application.
- The tool exits with code `0` (success), `1` (user error/validation), or `2` (unexpected exception).
